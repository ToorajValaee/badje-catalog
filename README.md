# بادجه — HTML Catalog Engine

This repository contains the deployable Badje catalog application. Uploaded PDFs are preserved as originals, rendered into WebP screens, and PDF link annotations are recreated as transparent HTML hotspots.

The admin can choose render quality per catalog and regenerate the web version later from the original PDF without re-uploading it.
